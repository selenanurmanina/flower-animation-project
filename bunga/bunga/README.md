# 🌸 Blooming Flowers Animation

Aesthetic animated flowers growing under a beautiful night sky, created with HTML, CSS, and JavaScript.

This project features a dreamy digital garden with animated flower growth, glowing details, and smooth visual effects.

## ✨ Features

- 🌷 Animated blooming flowers
- 🌙 Night-themed background
- ✨ Decorative glowing effects
- 🌿 Animated leaves and grass
- 💻 Lightweight web-based animation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```text
blooming-flowers-animation/
├── index.html
├── main.js
├── css/
│   └── main.css
├── img/
│   └── flowers.png
└── README.md
```

## 🚀 How to Run

1. Clone this repository.
2. Open the project folder.
3. Make sure all CSS, JavaScript, and image files are included.
4. Open `index.html` in your web browser.

## 🎨 Project Purpose

This project explores creative front-end development through CSS animations and interactive visual elements.
